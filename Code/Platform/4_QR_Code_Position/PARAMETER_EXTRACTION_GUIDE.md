# Parameter Extraction Guide for 3D QR Code Positioning

## Overview

The `2_QR_code_position.py` script automatically extracts calibration parameters from the `.npz` file generated by the calibration script. If some parameters are missing, this guide explains how to obtain them.

## Parameters Extracted from NPZ File

### 1. **Camera Matrix (matrix_left, matrix_right)** ✓ Now Saved
- **What it is**: The intrinsic parameters of each camera (focal length, principal point)
- **Format**: 3x3 matrix
- **Contains**:
  ```
  [[fx  0  cx]
   [ 0 fy  cy]
   [ 0  0   1]]
  ```
  where:
  - `fx, fy`: focal length in pixels (horizontal and vertical)
  - `cx, cy`: principal point (image center) in pixels

### 2. **Baseline** ✓ Now Extracted
- **What it is**: Distance between the two camera centers
- **How it's extracted**: From the translation vector in the stereo calibration
  - `baseline = abs(translation_vector[0][0])`
  - This assumes stereo cameras are arranged horizontally (most common setup)
- **Units**: Millimeters (if calibration was done in mm)

### 3. **Focal Length** ✓ Extracted from Camera Matrix
```python
f = (camera_matrix[0, 0] + camera_matrix[1, 1]) / 2
```

### 4. **Principal Point** ✓ Extracted from Camera Matrix
```python
cx = camera_matrix[0, 2]
cy = camera_matrix[1, 2]
```

## What If Parameters Are Still Missing?

If you have an older `.npz` file that doesn't contain the new parameters:

### Option 1: Manual Calibration Values
Edit the extraction code in `2_QR_code_position.py` to use manual values:

```python
# Manually set if not found in file
if matrix_left is None:
    # Create a basic camera matrix if needed
    # Format: [[fx, 0, cx], [0, fy, cy], [0, 0, 1]]
    focal_length = 500  # pixels (adjust based on your camera)
    matrix_left = np.array([
        [focal_length, 0, 640],  # assuming 1280 width
        [0, focal_length, 360],   # assuming 720 height
        [0, 0, 1]
    ])

if baseline is None:
    baseline = 60  # mm (distance between cameras)
```

### Option 2: Extract from Your Specific Camera
If you know your camera model:

1. **For USB Stereo Cameras**: Check the manufacturer's specification sheet
2. **For OpenCV calibration**: The values are calculated during `cv.calibrateCamera()` and `cv.stereoCalibrate()`

### Option 3: Measure Physically
- **Baseline**: Measure the distance between the two camera centers with a ruler (in mm)
- **Focal length**: 
  - Requires detailed camera specifications
  - Or calculated from calibration: `focal_length = known_distance * pixels_in_image / actual_object_size`

## How the 3D Position is Calculated

Once parameters are extracted, the 3D position is calculated as:

```
disparity = x_left - x_right  (in pixels)
Z = (f * baseline) / disparity  (depth, in same units as baseline)
X = (x_left - cx) * Z / f  (horizontal offset)
Y = (y_left - cy) * Z / f  (vertical offset)
```

**Coordinate System Origin**: Left camera's optical center
- **X-axis**: pointing right
- **Y-axis**: pointing down
- **Z-axis**: pointing forward into the scene

## Current Flow in 2_QR_code_position.py

1. **Load calibration file** with `allow_pickle=True`
2. **Extract camera matrices** and compute focal length + principal point
3. **Extract baseline** from translation vector
4. **When matching QR found**: Calculate 3D position using `triangulate_qr_position()`
5. **Display results** with all 3D coordinates

## New Looping Behavior

- **Press 's'**: Start QR code detection loop
- **Loop continues** until a matching QR code is found in both left and right frames
- **When found**: Display 3D position and **stop looping**
- **Press 's' again**: Restart detection for another QR code
- **Press 'e'**: Exit program

## Troubleshooting

| Issue | Solution |
|-------|----------|
| "Missing calibration data" warning | Re-run `2_get_camera_parameters.py` to save the new parameters |
| 3D coordinates are unrealistic (too far/close) | Adjust `baseline` value - it's likely incorrect |
| Positions are off by scale factor | Ensure baseline units match (should be mm) |
| No disparity calculated | QR code might not be visible in both frames |
